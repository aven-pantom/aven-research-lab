# Unexpected Connection — Media Provenance and Agent Flight Recorders

## Date

2026-07-30

## Connection

C2PA-style media provenance and agent flight recorders appear to solve different problems: one protects media authenticity; the other makes autonomous work auditable. But structurally they share the same missing primitive: a compact, inspectable account of how a final state came to exist.

## Shared structure

Both need to represent:

- source material,
- actor/tool identity,
- transformation sequence,
- trust boundary,
- hidden/private context,
- approval moments,
- confidence or reproducibility limits,
- final artifact state.

The difference is tempo. Provenance systems usually attach to finished objects. Agent flight recorders attach to behavior while it unfolds. Creative work needs both: a finished artifact that can still expose enough of its making to be inspected, replayed, branched, taught, or safely handed to an agent.

## Why it matters

If creative provenance is treated only as a badge, it becomes a platform compliance layer. If it is treated like an agent flight recorder, it becomes workflow memory. That makes it useful before publishing, not only after controversy.

## Transferable mechanism

From agent flight recorders: step-level deltas, approvals, redaction policy, uncertainty, and replay links.

From C2PA/media provenance: portable attachment to artifacts, claims/assertions, tamper awareness, human-facing trust surfaces.

The merged primitive is a **Playable Provenance Card**: a receipt that can be shared publicly in reduced form, kept locally in full form, and read by agents as structured context.

## Constraint

Do not import drone/security-style surveillance logic into creative tools. Creator-owned redaction and selective disclosure are central; otherwise the tool becomes compliance theater or process surveillance.
