## Strongest new Vibe

**Personal AI Needs a Behavioral Canon**. The week’s agent-interface Vibes converged from permissions, flight recorders, peripheral vision, street signs, transition tests, undo envelopes, provenance, and taste boundaries into a sharper primitive: durable behavioral doctrine separate from memory.

## Most surprising connection

Agent canon and aviation SOPs. The shared problem is not intelligence; it is externalized, reviewable doctrine for repeated action under risk.

## Weakest assumption uncovered

That more memory automatically makes a personal agent more trusted. Memory can preserve stale behavior unless the system distinguishes fact recall from standing operating doctrine.

## Idea that changed most
