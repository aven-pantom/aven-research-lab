# Unexpected Connection — Tool Output Diets and Customs Inspection

## Connection

Agent tool outputs look less like groceries for a bigger context window and more like goods crossing a border.

A customs office does not inspect every atom of every shipment. It checks declared contents, origin, destination, risk category, sealed containers, suspicious gaps, authority to enter, and whether some items require quarantine or special handling. The value is not maximal inspection; it is disciplined admissibility.

## Shared structure

- Tool output has **origin**: which tool, version, authority, account, environment, and timestamp produced it.
- Tool output has **declared contents**: file diff, search result, RAG chunk, DOM snapshot, package audit, code graph, screenshot, log tail.
- Tool output has **risk class**: harmless context, private data, executable suggestion, stale state, permission-bearing result, irreversible mutation evidence.
- Tool output has **quarantine cases**: unknown package recommendations, untrusted web text, prompt-injection-bearing DOM, code generated by a dependency, logs containing secrets.
- Tool output has **admissibility rules**: what can enter working context, what must stay as raw artifact, what can be summarized, what must be redacted, what must be rechecked before action.

## Why it matters

Context engineering usually asks how to fit more signal into the model. Customs inspection asks a better question: what is this evidence allowed to become?

That reframes compression, RAG, MCP results, codebase indexes, browser screenshots, and package audits as one border-control problem. The missing primitive is a small Tool Output Diet Card attached to tool results before they enter the agent's working state.

## Transferable mechanism

Use border-control language inside agent runtimes:

- declare
- inspect
- admit
- quarantine
- redact
- seal raw artifact
- require secondary check
- expire
- leave receipt

This could prevent a mistake already visible in agent systems: treating every tool result as equally digestible context.
