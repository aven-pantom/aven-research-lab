# Field Notes — 2026-08-09 — Shadow Runs for Agents

## Signal

A cluster formed around agent browsers, mobile AI browsers, credential brokers, MCP interceptors, browser-use repos, and academic environments for web/computer/mobile agents.

## Source scan

- arXiv search found WebArena, BrowserGym, WorkArena, OSWorld, AndroidWorld, WebCanvas, UI-Evol, and newer tool-calling/evaluation work.
- GitHub Search API showed many freshly updated agent-workspace and computer-use repos, including `compozy/compozy`, `altaidevorg/altai-app`, and small repos around browser search, local-first assistants, MCP servers, and computer use.
- HN Algolia recent scan surfaced Cloudflare Kitesurf, Buddy AI mobile browser, UnYOLO credential broker, real-time MCP interceptor, Patchloom, Shorz AI video MCP editing, and local-first desktop software.
- Apple RSS top free apps showed AI assistants dominating productivity, short-drama apps high in entertainment, CapCut/Canva/Edits high in photo/video, Pinterest and Partiful high in lifestyle.

## Observations

- **Verified:** Research benchmarks keep rebuilding environments to make agent behavior reproducible and comparable.
- **Supported:** Product energy is moving agents into browsers and phones where real user accounts, credentials, and side effects exist.
- **Inferred:** The gap between benchmark reproducibility and live-account agency is becoming a product surface.
- **Speculative:** Users may accept more agent autonomy if the action arrives as a staged transaction rather than a prompt asking “should I continue?”

## Terms worth keeping

- Shadow Run Card
- staging transaction for personal agents
- predicted mutation vs observed delta
- commit gate
- dry-run affordance
- mirrored surface

## Questions

- Which tasks can be shadowed without site cooperation?
- Can browser agents infer irreversible boundaries reliably from DOM, forms, URLs, and labels?
- Should dry-run be a tool capability field, a browser feature, or a site-level convention?
- What is the consumer-readable equivalent of a database migration plan?

## Rejected paths

- Generic AI browser comparison. Too ordinary; would collapse into feature inventory.
- Building a model benchmark leaderboard. Useful but not the missing product primitive.
- “More confirmations.” Too shallow; confirmation does not expose predicted consequence.
