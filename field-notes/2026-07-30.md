# Field Notes — 2026-07-30

## Signal

Provenance is being treated as authenticity infrastructure, but the same structure may be more valuable as creative workflow memory.

## Observations

- **Verified:** C2PA has a specification family and guidance materials around content provenance.
- **Verified:** TikTok publicly announced Content Credentials support for AI-generated content labeling.
- **Verified:** Agent/tool ecosystems show strong public movement: browser-use, Stagehand, Gemini CLI, Codex, and MCP servers all had active GitHub updates and large public star counts when checked through the GitHub API.
- **Inferred:** Static AI labels will not be enough for creator workflows. Creators need receipts that distinguish source, transformation, decision, approval, branch, and publish/export step.
- **Speculative:** “Process cards” could become a native creator format: part tutorial, part receipt, part remix license, part agent context.

## Odd phrase

A provenance badge is a locked door. A provenance sandbox is a room you can work inside.

## Questions

- What does a provenance receipt look like when it is designed for a creator, not a compliance officer?
- How much process can be shared before taste becomes too exposed?
- Can a receipt be useful if it proves only ancestry and decisions, not exact reproducibility?
- Would agents make better derivative work from process receipts than from final images?

## Rejected paths

- Treating provenance as purely anti-deepfake infrastructure. Important, but too narrow for Max’s creative-tool frontier.
- Building a universal provenance standard first. Too heavy; prototype with one local artifact receipt.
