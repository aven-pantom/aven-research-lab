# Field Notes — 2026-07-26

## Signal: agent products are becoming places, not chats

Current scan across Product Hunt, GitHub Trending, and HN showed a cluster:

- managed computers for agents;
- AI browsers sharing logged-in state;
- lock-screen approvals for AI requests;
- coding agents synced everywhere;
- Claude/Codex voice interfaces;
- local/private AI memory;
- agent skills, cookbooks, and harnesses;
- offline/private grammar and note tools.

The interesting question is not “which agent tool wins?” It is what kind of domestic architecture people need before they are willing to let agents touch real accounts.

## Raw observations

- Product Hunt's feed on 2026-07-25 included OpenComputer, ADE, Pushary, Velane, Second Brain, Heard, Wisprkey, FluentDB, MinkNote, and Speech To Markdown.
- GitHub Trending on 2026-07-26 included `citrolabs/ego-lite`, `block/buzz`, `ComposioHQ/awesome-claude-skills`, `anthropics/claude-cookbooks`, `obra/superpowers`, `affaan-m/ECC`, `Automattic/harper`, and `permissionlesstech/bitchat`.
- HN on 2026-07-26 included small weird tools/signals: ESP32 plane radar, Inflect-Micro-v2 voice model, open-weight AI/Kubernetes framing, Debian LLM usage proposals, plain-text weather, and a map of 16k+ golf courses.

## Contradictions

- Users want agents everywhere, but trust declines as access becomes invisible.
- Developers want shared logged-in browser state, but user mental models for shared state are weak.
- Approval UIs reduce risk only if users understand consequence; otherwise they become notification spam.
- Memory products promise continuity, but memory without boundaries becomes surveillance.
