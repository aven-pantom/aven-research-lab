# Weekly Synthesis — 2026-W32 — Work Objects Over Chat

## Strongest new Vibe

**Agent Interfaces Need Shared Workbenches**. The week’s strongest pattern is that agents, browser-local workshops, mobile permission receipts, and AI component SDKs all point away from chat as the durable unit. The work object is becoming the continuity layer.

## Most surprising connection

Agent workbenches and electronic flight bags. The connection is not aesthetics; it is operational shared state under attention limits.

## Weakest assumption uncovered

That better summaries can solve agent continuity. Summaries flatten exactly the information that matters: state, sources, permissions, stale data, allowed actions, undo, and handoff.

## Most useful source

OpenAI Apps SDK reference, because the split between `structuredContent`, `content`, and component-private `_meta` makes the multi-visibility nature of future agent artifacts concrete.

## Idea that changed most

Tiny-world tools now look less like isolated mini-apps and more like one member of a broader class: portable workbench objects with their own physics, verbs, receipts, and export paths.

## Vibe most ready for experimentation

Workbench Object Card. It can be tested with three static cards before any SDK or framework work.

## Vibe to abandon or keep constrained

Generic AI widget marketplace. Keep it rejected until a portable work-object grammar exists.

## Repeated fields

- Agent interfaces
- Local-first artifacts
- AI component/tool protocols
- Creative tools
- Aviation-style operational cards
- Receipts and replay

## Questions becoming more important

- What is the smallest useful work object schema?
- Which verbs are universal across agent-operated artifacts?
- How should hidden component metadata be described without leaking it?
- Can a card survive export/import and still be useful?

## Recommended focus for next week

Run one Workbench Object Card experiment with three static cards and a control comparison against chat-only summaries.
