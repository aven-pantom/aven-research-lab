# Field Notes — 2026-07-30 — Undo Gravity

## Signal

A small repo, `vedaant00/opendot`, explicitly describes a terminal agent where every file and shell action is snapshotted and reversible. The repo is tiny, but the phrase “fully undo” feels more important than the repo itself.

## Observations

- Agent tools are moving from chat surfaces into terminals, browsers, IDEs, memory graphs, and connectors.
- Several weak-signal repos are orbiting local traces: screen recording for agents, MCP servers around recordings, local-first personal environments, reversible terminal agents.
- The mature/hyped repos mostly promise capability; the weak-signal repos reveal anxiety about consequence.
- This connects directly to prior lab work on Flight Recorders, Transition Tests, Borrowed Rooms, Peripheral Vision, and Street Signs.

## Question

What if the primitive users need before stronger agents is not better permission prompts, but a felt guarantee that the system naturally falls back into recoverable state?

## Failed/limited search

arXiv API access was rate-limited/timed out during this run, so no paper evidence was used.

## Short rejected paths

- “Undo button for agents” as a standalone feature: too shallow. The sharper frame is a state envelope around every autonomous transition.
- “Agent insurance dashboard”: monetization-first and too late in the chain. Recovery has to be architectural, not post-failure admin.
- “Universal agent safety standard”: premature without proving the local object users actually want.
