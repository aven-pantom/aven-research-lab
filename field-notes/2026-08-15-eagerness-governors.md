# Field Notes — 2026-08-15 — Eagerness Governors

## Raw signal

- OpenAI's GPT-5 prompting guide names “agentic eagerness” as a variable to control.
- MCP 2025-06-18 includes elicitation: servers can request structured user input through clients during nested workflows.
- MCP elicitation safety language already points toward visible requester identity, review/modify, decline, and cancel.
- Product Hunt feed is full of delegated-work language: business autopilot, coding-agent clones, phone cockpit for Claude Code/Codex, browser scraping agents, software factories, plugin harnesses.
- The lab has many agent trust primitives, but they mostly answer state/permission/receipt questions. The missing cross-cutting question is initiative.

## Odd phrases worth preserving

- “Autonomy should have throttles, not personality.”
- “Helpful is a runtime mode.”
- “A safe agent can still be too eager.”
- “Ask, draft, stage, act, stop” may be the simplest visible autonomy grammar.

## Contradictions

- Users want agents to continue until done, but also punish them when they infer past an invisible boundary.
- Prompt guides can tune eagerness, but prompt text is invisible at the moment a user needs mode awareness.
- MCP elicitation adds structured asking, but structured asking can still be too frequent, too late, or too invasive.

## Possible fixture tasks

1. Local Markdown cleanup: assertive act; no ask unless content semantics change.
2. Browser research: exploratory observe/research; cite before conclude.
3. Shopping return: conservative; ask before account mutation or shipment change.
4. Calendar reschedule: stage candidate; ask before sending.
5. CRM cleanup: draft/stage; never delete without approval.
6. Coding-agent bug fix: assertive in local code, stop at package install/config changes.
7. Phone assistant: observe locally; ask before messages, purchases, permissions, location sharing.

## Rejected path during wander

A generic “agent settings dashboard” is too broad. The sharper object is a task-scoped Eagerness Governor Card that travels with a work item and can be tested as a fixture.
