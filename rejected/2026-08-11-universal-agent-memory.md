# Rejected — Universal Agent Memory

## Why it initially seemed promising
Agent tools are proliferating, and it is tempting to frame the problem as persistent universal memory across all agents and apps.

## What evidence weakened it
Prior lab work has already mapped behavioral canon, flight recorders, permission receipts, and resident microbrains. A broad universal-memory frame adds little precision. The current source signal points more specifically to multi-surface execution and tool/component state.

## Which assumption failed
The weak assumption was that better memory is the main missing piece. For operational work, the missing piece is often resumability: what another surface can safely do next.

## Whether it may become viable later
A universal memory layer may matter later, but only after task-scoped continuation objects prove which memory fields are actually useful.

## Useful remnants
- Keep the phrase “memory is not resumption.”
- Watch for agent platforms exposing portable task state rather than only chat history.

## Future signal that should trigger reconsideration
A major agent platform ships exportable, user-owned cross-agent memory with explicit permission scopes, provenance, and verification gates.
