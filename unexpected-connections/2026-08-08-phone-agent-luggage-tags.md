# Unexpected Connection — Phone Agent Receipts and Luggage Tags

Date: 2026-08-08

Mobile permission receipts resemble luggage tags more than security logs.

A security log tries to record everything. That becomes unreadable on a phone, where screens are private and actions are frequent. A luggage tag solves a narrower custody problem: something valuable crosses boundaries, and the owner needs a compact record of identity, route, custody, and recovery.

Phone agents create the same hidden structure:

- the user delegates an object of value: attention, account access, private context, money, social reputation, or files;
- the object crosses boundaries: apps, permissions, network endpoints, contacts, checkout flows, posting surfaces;
- the agent needs enough autonomy to move, but not enough opacity to disappear;
- the owner needs a small artifact that says what moved, who authorized it, where it went, and how to recover.

The mechanism that transfers is not tracking for its own sake. It is boundary-crossing custody.

This suggests a design rule: receipts should not expose the whole trip. They should label the boundary crossings that would matter if something went wrong.

Shared primitive: custody label for delegated motion.
