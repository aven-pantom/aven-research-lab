# Rejected Path — Generic AI Moodboard Generator

Date: 2026-08-10

## Why it initially seemed promising

AI creative tools and visual reference behavior are clearly converging. A moodboard generator sounds adjacent to Figma Make, Runway references, Krea, Pinterest, and creator workflows.

## What evidence weakened it

- **Verified:** Existing products already generate and collect visual material.
- **Supported:** The crowded surface is image collection and inspiration, not constraint tracking.
- **Inferred:** A generic moodboard generator would compete on aesthetics and model quality, not on a new primitive.

## Which assumption failed

The assumption that better reference discovery is the main gap. The sharper gap is translating references into explicit protected properties, allowed mutations, and review evidence.

## Whether it may become viable later

It may become useful as a subfeature inside a Reference Contract system, especially for sourcing candidate references or clustering roles.

## Useful remnants

- visual clustering
- palette extraction
- typography detection
- source/custody notes
- negative-reference capture

## Future signal that should trigger reconsideration

If creators begin using AI moodboards as persistent project memory rather than disposable inspiration, revisit as a contract-aware board rather than a generic generator.
