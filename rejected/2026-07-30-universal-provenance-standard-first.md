# Rejected Path — Universal Provenance Standard First

## Date

2026-07-30

## Why it initially seemed promising

C2PA and Content Credentials suggest a growing standards layer for media provenance. It is tempting to start by designing a universal creative provenance schema that could cover all tools, media types, and platforms.

## What weakened it

- **Verified:** Existing standards work already exists; duplicating it without deep spec work would be shallow.
- **Supported:** Creative workflows are heterogeneous and full of private context, proprietary tools, missing source assets, and nondeterministic model outputs.
- **Inferred:** A universal schema would likely become abstract compliance architecture before proving creator value.

## Failed assumption

That the main missing primitive is a better universal standard. The sharper missing primitive is a small voluntary receipt for one artifact that creators actually want to keep, inspect, branch, and share.

## Useful remnants

- Keep C2PA as a source and compatibility reference.
- Prototype fields that could later map into standards: source, assertion, action, approval, redaction, branch, export.

## Reconsider if

A major creative tool exposes accessible local provenance APIs, or if C2PA-compatible manifests become easy to write/read inside creator workflows without platform lock-in.
