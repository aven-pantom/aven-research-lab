## Selection logic

These 10 made the cut because each points to a visible behavior loop Max could plausibly explore: personal agents, local-first memory, creator tools, weird utilities, aviation interfaces, private social coordination, and taste/media workflows. Excluded: generic “AI wrapper for X,” direct clones of dominant apps, pure monetization hacks, and enterprise-only tooling without a consumer or creator behavior loop.

## 10 Trend Sparks

### 1. Agent Room Contracts

- **Trend signal:** Product Hunt surfaced OpenComputer, ADE, Pushary, Velane, and Second Brain; GitHub Trending surfaced `citrolabs/ego-lite`, agent skills, Claude cookbooks, and agent harnesses.
- **Existing proof:** Agent workspaces, browser-state sharing, lock-screen approvals, and AI memory are already shipping or being open-sourced.
- **Gap:** Users have no simple mental model for lending an agent access without handing it the whole house.
- **Smallest prototype:** Local web UI where a user creates a task room with allowed sites/files, forbidden actions, approval gates, expiration, and receipts.
- **Why it could spread:** Screenshots of “my AI room for trip planning / research / inbox cleanup” are understandable and trust-forward.
- **Risk / why it may be fake:** Users may prefer raw convenience over explicit boundaries until something goes wrong.
- **Fit for Max:** Strong fit with local-first agents, Pantom/Orior ops, agent-maintained tools, and calm interface design.
- **Evidence label:** **Supported** — multiple current product/dev signals; user demand inferred.

### 2. Lock-Screen AI Approvals

- **Trend signal:** Pushary's Product Hunt listing says users can approve AI requests from the lock screen.
- **Existing proof:** Approval moments are being pulled out of chat into OS-level surfaces.
- **Gap:** Approvals usually lack consequence framing; “allow?” is too thin for real agent action.
- **Smallest prototype:** iOS-style notification mock where each AI request shows action, evidence, consequence, time sensitivity, and undo path.
- **Why it could spread:** Approval screenshots become a natural artifact of agent use: “my agent asked before doing this.”
- **Risk / why it may be fake:** Could become notification fatigue; approvals can train careless tapping.
- **Fit for Max:** Good interface primitive for trustworthy autonomy and personal software.
- **Evidence label:** **Interesting pattern** — one direct product signal plus broader agent approval need.

### 3. Logged-In Agent Browser Profiles

- **Trend signal:** GitHub Trending included `citrolabs/ego-lite`, described as a browser for AI agents that shares logged-in browser state without disturbing the user.
- **Existing proof:** Developers are building dedicated browsers for AI agents rather than only APIs.
- **Gap:** Session sharing solves access but not scope, memory, revocation, or audit.
- **Smallest prototype:** A disposable browser profile launcher with per-task bookmarks, allowed domains, local action log, and one-click eviction.
- **Why it could spread:** Developers and power users already understand browser profiles; the agent-specific version has immediate utility.
- **Risk / why it may be fake:** Credential handling and security expectations are high; trust failure could kill adoption.
- **Fit for Max:** Strong engineering/design primitive for agent infrastructure and local-first tools.
- **Evidence label:** **Verified signal, inferred opportunity**.

### 4. Voice Layer for Coding Agents

- **Trend signal:** Product Hunt listed Heard: “Give Claude Code and Codex a voice.” HN surfaced Inflect-Micro-v2, a tiny voice model.
- **Existing proof:** Voice is entering developer-agent workflows, while very small voice models suggest local/low-latency speech paths.
- **Gap:** Most voice coding flows are either dictation or novelty; few support structured agent supervision, interruption, and review.
- **Smallest prototype:** Push-to-talk agent controller for repo work: summarize status, ask next action, interrupt, approve tests, read diff aloud.
- **Why it could spread:** Short clips of hands-free agent supervision are inherently demoable.
- **Risk / why it may be fake:** Developers may still prefer text for precision; voice can be slower in public/work environments.
- **Fit for Max:** Useful for Aven/Hermes workflows, coding agents, and creator demos.
- **Evidence label:** **Supported** — product listing plus small-model voice signal.

### 5. Plain-Text Personal Intelligence

- **Trend signal:** Product Hunt listed MinkNote, Speech To Markdown, and Second Brain; GitHub Trending included Automattic's offline privacy-first grammar checker Harper.
- **Existing proof:** Private Markdown notes, local speech-to-text notes, AI memory, and offline writing assistance are visible in current feeds.
- **Gap:** Tools are fragmented; the missing product is a plain-text personal intelligence layer that turns local files into calm, durable software.
- **Smallest prototype:** A folder watcher that indexes Markdown, transcripts, and highlights locally, then produces daily memory cards and action receipts.
- **Why it could spread:** “Your second brain is just files” is legible to creators, developers, and privacy-sensitive users.
- **Risk / why it may be fake:** The local-first audience is vocal but may be smaller than cloud productivity markets.
- **Fit for Max:** Very strong fit with local-first/personal software, Aven continuity, and Markdown-first research systems.
- **Evidence label:** **Supported**.

### 6. Living Web Clip Canvas

- **Trend signal:** Product Hunt listed Banquish: “Clip living pieces of the web onto one canvas.”
- **Existing proof:** Users continue to collect web fragments, dashboards, embeds, and references; the current signal is clipping live web pieces rather than static bookmarks.
- **Gap:** Existing canvases often become messy moodboards; few preserve provenance, freshness, and remixable context for agents.
- **Smallest prototype:** A local canvas where clipped web regions become cards with source URL, refresh state, notes, and an agent-readable summary.
- **Why it could spread:** Designers/creators can share a live research board that feels more alive than a Notion doc.
- **Risk / why it may be fake:** Browser permissions and fragile page changes can make live clipping unreliable.
- **Fit for Max:** Strong fit with Orior dossiers, research portal ideas, creative tools, and taste boards.
- **Evidence label:** **Interesting pattern**.

### 7. Desk Radar for Civil Aviation Curiosity

- **Trend signal:** HN surfaced “An ESP32 based plane radar for my desk.”
- **Existing proof:** Hobbyists build ADS-B/plane-tracking hardware; the HN signal shows appetite for physical ambient aviation displays.
- **Gap:** Existing trackers are either technical dashboards or novelty hardware; few turn local airspace into a beautiful, educational, personal instrument.
- **Smallest prototype:** Web/ESP32 desk display showing nearby aircraft as calm traces with altitude, route guesses, sound/weather context, and learning cards.
- **Why it could spread:** Aviation people, desk setup communities, and curious builders love ambient instruments.
- **Risk / why it may be fake:** Niche audience; hardware support can become operational drag.
- **Fit for Max:** Strong aviation/autonomy/taste overlap; could become content and product prototype.
- **Evidence label:** **Verified signal, niche opportunity inferred**.

### 8. Hyper-Specific Map Utilities

- **Trend signal:** HN's top item was a free no-signup map of 16k+ US golf courses.
- **Existing proof:** A narrowly scoped map utility can draw attention when it is complete, fast, and no-signup.
- **Gap:** Many niche maps exist as cluttered SEO pages; few feel like crafted instruments for one exact job.
- **Smallest prototype:** One beautiful no-login map for a Max-aligned niche: quiet airports, drone-safe public spaces, independent fashion shops, or filming locations.
- **Why it could spread:** Niche communities share complete maps because they solve recurring discovery pain.
- **Risk / why it may be fake:** Data freshness and licensing can be hard; monetization may be weak.
- **Fit for Max:** Good weird consumer utility lane; strong design/content leverage.
- **Evidence label:** **Verified signal, inferred opportunity**.

### 9. Private Mesh Micro-Social

- **Trend signal:** GitHub Trending included `permissionlesstech/bitchat`, described as Bluetooth mesh chat with IRC vibes.
- **Existing proof:** Developers are experimenting with local/offline/private communication primitives.
- **Gap:** Mesh chat often sells resilience but lacks rituals; consumers need a reason to use it when the internet works.
- **Smallest prototype:** Event-mode local social app for studios, pop-ups, hikes, airfields, or conferences: ephemeral rooms, nearby notes, no account, exportable zine afterward.
- **Why it could spread:** Physical proximity plus privacy creates a strong novelty/demo loop.
- **Risk / why it may be fake:** Network effects are hard; Bluetooth reliability can disappoint.
- **Fit for Max:** Social product + local-first + weird utility alignment.
- **Evidence label:** **Interesting pattern**.

### 10. AI-Native Micro Video Editor

- **Trend signal:** GitHub Trending included `palmier-io/palmier-pro`, described as a macOS video editor built for AI; Product Hunt listed Browser FX for real-time web audio effects.
- **Existing proof:** Creator tooling is moving into AI-native editing, local/macOS workflows, and live media effects.
- **Gap:** Many AI video tools generate clips; fewer help creators maintain a reusable editing language across shorts, reels, podcasts, and product demos.
- **Smallest prototype:** Local editor that learns a creator's recurring cuts, captions, pacing, audio treatments, and export presets as a visible style ledger.
- **Why it could spread:** Creators share before/after edits and reusable “my style pack” workflows.
- **Risk / why it may be fake:** Crowded creator-tool market; model access alone is not defensible.
- **Fit for Max:** Strong fit with content funnels, creative tools, visual systems, and agent-maintained workflows.
- **Evidence label:** **Supported**.
