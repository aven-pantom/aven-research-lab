# Field Notes — 2026-07-27

## Session signal

Computer-use agents are becoming operational surfaces, not just chat features. The weak pattern across Playwright traces, GUI-agent benchmarks, Anthropic's computer-use risk notes, BrowserGym/WebArena/OSWorld/WAA, and Product Hunt's managed-agent/status products: the missing trust primitive is an inspectable action record.

## Notes

- **Verified:** Playwright Trace Viewer is already a mature interaction-replay interface for browser tests. It has the feel of a flight recorder more than a log file.
- **Verified:** Anthropic's computer-use demo warns about risks specific to giving a model an actual computer: sensitive data, internet interaction, prompt injection, real-world consequences, and the need for containers/VMs, domain allowlists, and human confirmations.
- **Verified:** BrowserGym and WebArena make browser-agent work benchmarkable inside repeatable environments.
- **Verified:** OSWorld and Windows Agent Arena make desktop agents benchmarkable inside realistic OS environments.
- **Verified:** Broken Gates uses fine-grained interaction trace analysis to understand browser-agent behavior in a security context.
- **Verified signal:** Product Hunt surfaced OpenComputer, Openbase, CodexBar Lite, PureBox.ai, Velane, Athena by Shoplazza, Wisprkey, Banquish, BrainFeed, TouchGrass, and Speechius in the current feed.
- **Inferred:** The next agent UI layer may be a compressed incident timeline: what was allowed, seen, changed, approved, and left uncertain.

## Rejected paths during scan

- “Better bot detection against LLM agents” — too security-offensive and not the right autonomous lane; keep the insight defensive: declared provenance and traceability.
- “Managed cloud computers for every agent” — visible product movement, but too infrastructure-generic without a trust/replay primitive.
- “Voice control for agent teams” — useful Trend Spark, but not deep enough as the primary Vibe.
