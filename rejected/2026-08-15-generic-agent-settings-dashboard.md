# Rejected — Generic Agent Settings Dashboard

## Why it initially seemed promising

Agent products need controls for autonomy, permissions, tools, context, memory, notifications, and receipts. A dashboard sounds like the obvious interface.

## What evidence weakened it

The current signal is narrower: OpenAI prompt guidance names eagerness, MCP elicitation creates nested ask moments, and delegated-work products are proliferating. The painful primitive is not global settings; it is task-specific initiative.

## Which assumption failed

Assumption: users need a place to configure agents.

Better assumption: users need the active task to carry a small visible autonomy contract that says when the agent may continue, ask, stage, act, or stop.

## Useful remnants

- Some global defaults may exist later.
- A personal behavioral canon can set defaults for recurring work.
- Workbench UI may show the current card, but the card should remain attached to the work item.

## Future signal for reconsideration

Reconsider a broader dashboard only after 20–50 Eagerness Governor Cards reveal repeated user-level defaults that should be promoted into a durable personal policy layer.
