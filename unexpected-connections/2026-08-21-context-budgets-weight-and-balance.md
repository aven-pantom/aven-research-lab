# Unexpected Connection — Context Budgets and Aircraft Weight-and-Balance

## Connection

Agent context has the same hidden structure as aircraft weight-and-balance.

An aircraft can contain many useful things, but not all of them belong on this flight. The issue is not only total weight; it is distribution, reserve, mission role, and consequence if conditions change. A safe load sheet turns invisible capacity into an operational decision before takeoff.

Agent work has the same failure mode. A model can ingest memories, rules, files, retrieved chunks, tool descriptors, browser state, previous chat, and project doctrine. More context can improve performance, but it can also shift attention, bury constraints, import stale assumptions, leak private material, or make an action look justified by irrelevant evidence.

## Shared structure

- **Capacity is finite but not self-explanatory.** Tokens, attention, recency, and instruction priority are all limited in ways users do not naturally see.
- **Distribution matters.** Ten thousand tokens of stale documentation can be more dangerous than a smaller, balanced set of objective, constraints, current state, and evidence.
- **Mission changes the load.** A research task, file edit, credential action, purchase, and deploy should not carry the same context mix.
- **Reserve matters.** Long tasks need reserved attention for new evidence, corrections, and irreversible-boundary checks.
- **Overload creates false confidence.** Too much context can feel thorough while reducing actual controllability.

## Implication

The useful primitive is not “bigger context.” It is a **Context Budget Card**: what this task is allowed to carry into working memory, what it must keep reserved, what it must exclude, what is stale, and what revalidation is required before action.

## Evidence label

**Inferred:** The structural analogy follows from verified movement toward explicit agent context surfaces and the known operational role of load/budget artifacts in safety-critical systems. It is not yet validated as an agent UX improvement.
