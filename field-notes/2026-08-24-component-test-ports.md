# Field Notes — 2026-08-24 — Component Test Ports

## Signal

- **Verified:** arXiv search on 2026-08-24 surfaced `2608.18307v1`, *ComponentBench*, which names a missing middle layer in GUI-agent evaluation: realistic component-centered interactions between long workflows and atomic grounding.
- **Verified:** The same search cluster surfaced `LegacyWorld` on atomicity-aware GUI-agent evaluation, `Screenshots or Tools?` on hybrid GUI-MCP routing and context management, `UI-Mate` on demonstration-guided open-weight GUI agents, and `Same-Origin Policy for Agentic Browsers` on security boundaries.
- **Verified:** GitHub API scan showed active public tooling around browser agents, MCP servers, computer-use drivers, local-first code/workspace graphs, AI-agent-operated video timelines, and screen-recording evidence loops.

## Odd technical result

ComponentBench reports that changing only observation/action space can shift task success by more than 30 percentage points for the same model. That implies some failures are interface-representation failures, not only model-intelligence failures.
