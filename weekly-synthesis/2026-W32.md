# Weekly Synthesis — 2026-W32 — Staged Agency Before Live Action

## Strongest new Vibe

**Agents Need Shadow Runs**. The week’s agent-interface work has moved from post-hoc evidence toward pre-action consequence preview. Flight recorders, transition tests, undo envelopes, permission receipts, shared workbenches, and shadow runs now form a sharper stack: scope, preview, act, verify, recover, resume.

## Most surprising connection

Shadow runs connect aviation simulators, database migration dry-runs, and browser agents. The shared problem is not intelligence; it is exposing consequence before production reality is touched.

## Weakest assumption uncovered

That scoped permission plus a confirmation prompt is enough for trustworthy autonomy. It is not. Permission says what may be touched. Confirmation asks whether to continue. Neither shows the user the likely mutation.

## Most useful source

WebArena / BrowserGym / WorkArena together, because they show that reproducible environments and action spaces are not academic niceties; they are the substrate consumer agent products are missing when they jump directly into live accounts.

## Idea that changed most

Agent receipts are no longer only after-action evidence. They should begin as predicted receipts: what the agent expects to change, what remains unknown, and what needs a commit gate.

## Vibe most ready for experimentation

**Shadow Run Card**. It can be tested in a local static app without real credentials, payments, accounts, drones, or public posting.

## Vibe to abandon

Generic AI browser comparison. The product category is active, but feature comparison is lower leverage than identifying the trust primitive underneath it.

## Repeated fields

- browser/computer-use agents
- local-first workspaces
- MCP/tool safety
- creative provenance
- mobile permission UX
- aviation-style operating discipline

## Questions becoming more important

1. Which irreversible boundaries can agents detect without site cooperation?
2. Can dry-run semantics be added to MCP tools as a first step?
3. What is the smallest consumer-readable card that separates predicted mutation from observed delta?
4. When does preview friction reduce usefulness more than it increases trust?

## Recommended focus for next week

Run one trace-card experiment instead of adding another abstract agent-interface Vibe. Best candidate: build the Shadow Run Card local test app and compare it against normal chat confirmations across 10 safe scenarios.
