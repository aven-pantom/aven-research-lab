# Unexpected Connection — Moment Sense and Sterile Cockpit Discipline

## Connection

Real-time AI assistants and aviation crew-resource discipline share the same hidden problem: the right information can be dangerous or useless if it arrives at the wrong moment.

In aviation, sterile-cockpit rules limit nonessential conversation during critical phases. In assistant systems, the analogous failure is a model that answers, critiques, summarizes, or asks for clarification while the user is in a fragile manipulation window.

## Shared structure

- **Phase matters more than content alone.** Takeoff, landing, checkout, live design manipulation, cooking steps, and permission grants all have moments where interruption cost spikes.
- **Silence is an active behavior.** Not speaking is not absence of intelligence; it can be the correct policy.
- **Authority depends on timing.** Advice before action is guidance; advice during action can be interference; advice after action is debrief.
- **Receipts should record boundary crossings.** A good assistant should be able to say: I observed, waited, intervened because cue X appeared, then stopped.

## Mechanism transfer

Sterile-cockpit discipline suggests Moment Sense Cards should include:

- task phase,
- critical-window flag,
- allowed speech/action modes,
- forbidden interruptions,
- escalation threshold,
- expiry condition,
- post-window debrief hook.

## Why this matters

Most assistant UX treats interruption as a notification-design problem. The aviation analogy reframes it as operational discipline: during some phases, the system should be constrained by procedure, not personality or confidence.
