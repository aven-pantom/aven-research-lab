# Rejected Path — Vector Memory as the Core Personal AI Primitive

## Why it initially seemed promising

The source cluster around personal AI systems repeatedly mentions local memory, persistent memory, life memory, knowledge bases, and agents that learn from the user. Better memory looks like the obvious core primitive.

## What weakened it

The more interesting repos and HN signals also mention permission gates, skills, automation, local control, credential boundaries, notebooks, browser QA, and transcript analysis. These are action-governance problems, not only recall problems.

## Which assumption failed

Assumption: if a personal AI remembers enough, it will naturally behave correctly.

Failure: behavior requires doctrine. The agent needs to know what kind of action culture it is living inside: when to interrupt, what to avoid, what is reversible, what standards matter, and how to update after mistakes.

## Whether it may become viable later

Vector memory remains necessary infrastructure. It becomes more valuable when paired with canon extraction, evidence receipts, scope, expiration, and user review.

## Useful remnants

- Memory events can supply evidence for Canon Cards.
- Transcript embeddings can help discover repeated corrections.
- Retrieval can surface relevant doctrine at action time.

## Future signal that should trigger reconsideration

If a personal AI system demonstrates strong autonomous behavior purely from memory traces without explicit doctrine, permissions, or review rituals, revisit this rejection.
